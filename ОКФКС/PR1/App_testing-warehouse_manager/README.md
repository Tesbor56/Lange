# Учёт товаров на складе

Приложение для учёта товаров на складе в целях учебного тестирования.

## Возможности

- Добавление товаров (артикул, наименование, категория, количество, цена, дата, комментарий).
- Просмотр списка товаров в таблице.
- Поиск по наименованию и артикулу.
- Фильтрация по категории и количеству.
- Подсчёт общего количества и общей стоимости.
- Статистика по категориям.
- Экспорт в CSV.
- Сохранение и загрузка данных в JSON.
